A world where we know the truth

We generate 100 sample points from

  • True .
import numpy as np

np.random.seed(123)
x = np.random.normal(
    loc=0, scale=1, size=100
)
eps = np.random.normal(
    loc=0, scale=np.sqrt(0.25), size=100
)
y = -1 + 0.5 * x + eps
y↓Assign tox↓eps↓
We specify the world before collecting its data. N(0,0.25) uses variance 0.25, so the error standard deviation is 0.5. In this simulation we know the generating rule and the true coefficients. With real data we observe x and y, but normally do not know the coefficients or each error.
